# Vendored source

This project was extracted from the Dokploy Aspire integration in
[`ScarletPigs/ScarletPigsServices`](https://github.com/ScarletPigs/ScarletPigsServices).
That integration itself records earlier provenance from
[`Ridderrasmus/DokployDeploy`](https://github.com/Ridderrasmus/DokployDeploy).

The standalone package keeps the imported source structure, updates repository
and packaging metadata for this repository, and restores NuGet packing so the
integration can be published independently.

The original MIT license is preserved in `LICENSE`.
