# Samples

These samples follow the official Aspire repository pattern of small, focused AppHosts with nearby projects.

| Sample | Shows |
| --- | --- |
| `SimpleWebApp` | Project deployment with hosted registry configuration and custom Dokploy domains |
| `ContainerVolume` | Container deployment with a self-hosted registry and persistent volume |
| `RunOnceJob` | One-shot project deployment using `RunOnce` |
